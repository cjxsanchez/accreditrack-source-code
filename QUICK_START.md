# AccrediTrack Quick Start Guide

## 🚀 Getting Started in 5 Minutes

### Step 1: Access the System
Open your browser and go to:
\`\`\`
http://localhost/accreditrack/
\`\`\`

### Step 2: Login as Admin
\`\`\`
Username: admin
Password: admin123
\`\`\`

### Step 3: Create Your First Program
1. Click **"Programs"** in the sidebar
2. Click **"Add Program"** button
3. Fill in:
   - Program Name: "Bachelor of Science in Information Technology"
   - Program Code: "BSIT"
   - Description: (optional)
4. Click **"Add Program"**

### Step 4: Add a Level
1. Click **"Add Level"** next to your program
2. Select level type (Level 1, Level 2, or Preliminary)
3. Click **"Add Level"**
   - ✨ System automatically creates 10 areas!

### Step 5: Register a Staff Member
1. Open a new tab: `http://localhost/accreditrack/register.php`
2. Fill in the registration form
3. Go back to admin dashboard
4. Click **"User Management"**
5. Approve the registration

### Step 6: Assign Staff to Area
1. In User Management, find the approved staff
2. Click **"Assign"** button
3. Select Program, Level, and Area
4. Click **"Assign"**

### Step 7: Test Staff Login
1. Logout from admin
2. Login with staff credentials
3. View assigned area
4. Upload a test document

## ✅ You're All Set!

Your AccrediTrack system is now ready to use.
